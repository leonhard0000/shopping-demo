# NovaCart

NovaCart 是一個以純前端實作的購物商城 Demo，包含主題式首頁、產品列表、分類篩選、搜尋功能，以及互動式購物車。

## 功能特色

- 精選商品展示區與電商首頁布局
- 產品搜尋與分類篩選
- 加入購物車與數量調整
- 小計、運費與總金額計算
- 可直接在瀏覽器中開啟使用

## 技術堆疊

- HTML
- CSS
- JavaScript

## 專案結構

- `index.html`：頁面結構
- `style.css`：樣式與版面設計
- `script.js`：產品資料與購物車邏輯

## 本地使用方式

### 方式 1：直接開啟

1. 直接在瀏覽器中打開 `index.html`
2. 即可查看頁面與互動功能

### 方式 2：利用本地伺服器

在專案根目錄執行：

```bash
python -m http.server 8000
```

之後在瀏覽器開啟：

```text
http://localhost:8000
```

## 主要畫面

- Hero 區塊
- 品類分類區
- 熱銷產品列表
- 促銷活動區
- 顧客評價區
- 右側購物車面板

## 自訂說明

如果要擴充此專案，可以在 `script.js` 中修改產品資料陣列，新增商品名稱、分類、價格與顏色主題。也可以直接調整 `style.css` 來更新品牌風格與介面配色。
