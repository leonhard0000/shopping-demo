# NovaCart

NovaCart 是一個以純前端實作的購物商城 Demo，包含主題式首頁、產品列表、分類篩選、搜尋功能、購物車互動，以及會員註冊示範。

## 功能特色

- 精選商品展示區與電商首頁布局
- 產品搜尋與分類篩選
- 加入購物車與數量調整
- 小計、運費與總金額計算
- 會員註冊表單與基本驗證
- 註冊成功後資料會寫入瀏覽器本地儲存
- 可直接在瀏覽器中開啟使用

## 目前註冊機制說明

此專案的會員註冊目前是前端 Demo 版本，註冊成功後會將帳號資料寫入瀏覽器的 `localStorage` 與 `sessionStorage`。

這代表：

- 註冊資訊會被保存
- 保存位置是使用者瀏覽器本地，不是後端資料庫
- 此做法僅適合 Demo / 研究用途，不適合真實上線環境

## 安全風險提醒

目前版本存在以下資安風險：

- 密碼以明碼方式保存，未做雜湊
- `localStorage` 可被前端腳本直接讀取，容易遭 XSS 攻擊
- 沒有後端驗證與權限控管
- 沒有 HTTPS、JWT / Session 安全機制
- 不適合處理真實使用者帳號資料

> 這個專案目前僅供學習、展示與前端互動開發使用，不能直接用於正式的會員系統。

## 專案結構

- `index.html`：頁面結構
- `style.css`：樣式與版面設計
- `script.js`：產品資料、購物車邏輯與註冊流程

## 本地使用方式

### 方式 1：直接開啟

1. 直接在瀏覽器中打開 `index.html`
2. 即可查看頁面與互動功能

### 方式 2：利用本地伺服器

在專案根目錄執行：

```bash
python -m http.server 8000
```

之後在瀏覽器開啟：

```text
http://localhost:8000
```

## 自訂說明

如果要擴充此專案，可以在 `script.js` 中修改產品資料陣列，新增商品名稱、分類、價格與顏色主題。也可以直接調整 `style.css` 來更新品牌風格與介面配色。
